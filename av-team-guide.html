How to use the dashboard to check file statuses, view AV requirements, and download approved files.

Open Dashboard

Your dashboard

Bookmark this URL

Open the dashboard in any browser on macOS or Windows. No login, no install required.

https://ibmzdc.github.io/av-management/dashboard.html

Refresh the page at any time — press ⌘R on Mac or F5 on Windows — to load the latest data. The dashboard updates within 60 seconds of any change made by the admin.

Understanding file statuses

Every session file has one of three statuses. Check the badge before taking any action.

Ready
Approved for projection

File has been received and approved. Download it and load it onto the playback machine.

Updated
Replacement received today

A newer version of this file was delivered. Download it immediately and replace any local copy you already have.

On hold
File not yet received

Do not project. Check back before the session. If it is still On hold close to start time, alert the AV lead immediately.

Downloading a file

  1. 1
    Confirm the status is Ready or Updated

    Never download a file marked On hold — it may be an incomplete draft.

  2. 2
    Check the Updated at timestamp

    The Updated column shows when the file was last changed. If you already have a copy, compare timestamps. Always use the most recent version.

  3. 3
    Click Download latest

    The link downloads directly from IBM Box. You will need to be signed into Box with the IBM-shared account that was granted access.

  4. 4
    Replace your local copy if needed

    If you already have an older version loaded on the playback machine, keep the old copy as a backup first, then replace it with the new download.

Files with a Updated badge or a New / Changed highlight are ones that changed since the last refresh. Prioritise reviewing those first.

Filtering and searching

Use the four controls at the top of the dashboard to narrow the file list to exactly what you need.

ControlHow to use it
Event dayFilter to a single day, or select All days for a full view. Start each morning by switching to the current day.
StatusUse Approved for projection as your default — shows only Ready and Updated files. Switch to All files to see On hold sessions too.
SearchType any part of a session title or file name to find it instantly, e.g. keynote or recap.
SortMost recently updated surfaces new arrivals first. Session time puts the list in run-of-show order.

Viewing AV production details

Each session row includes a View AV details button where production requirements have been entered. Click it to expand the full AV setup for that session.

DetailWhat it covers
MicrophonesNumber and type of mics required on stage, e.g. 2 handheld, 1 lav.
Stage setupPhysical layout — podium, panel, fireside chat, etc.
Confidence monitorWhether a monitor is required and where, e.g. Yes, downstage center.
ClickerWhether a slide clicker is needed.
TimerSession length or countdown timer setting in minutes.
Special AV notesAnything non-standard — walk-on music, live demo, audio level check, etc.

Today's change log

The change log panel (bottom-left of the dashboard) lists every update made since the last refresh — newest entry first. Check it at the start of each session block to catch any last-minute file swaps or status changes.

If you see a change log entry for a session that is already loaded on your playback machine, download the updated file immediately and replace your local copy before that session begins.

Operational rules

  • Only download files with status Ready or Updated.
  • Always use the file with the most recent Updated at timestamp.
  • Before replacing any file already used on stage, save a local backup of the old version.
  • Check the dashboard before each session block — not just once in the morning.
  • If a file shows Updated, download and replace your local copy before that session begins.
  • If a file remains On hold within 30 minutes of the session start, alert the AV lead immediately.
  • Read Operator notes for each file — they contain session-specific instructions from the AV lead.
  • For videos, check the Special AV notes field for audio level requirements before playback.
